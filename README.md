# ⚡ Aevion Studio — AI Software & Digital Engineering Studio

Aevion Studio is a premium AI software & digital engineering studio that builds modern websites, web applications, AI-powered solutions, SaaS products, automation systems, internal tools, dashboards, and custom software for startups and enterprises.

---

## ✨ Core Pillars

*   **AI Software Development**: Intelligent workflows, custom LLM integrations, and automated decision engines.
*   **Modern Web Applications**: Fluid, high-performance web products crafted with Next.js, GSAP, and Tailwind.
*   **SaaS Engineering**: Scalable multi-tenant architectures, dashboards, and robust API design.
*   **Business Automation**: Custom software solutions that streamline operations and elevate productivity.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Animation**: [GSAP](https://gsap.com/) & [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 📂 Project Structure

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open your browser**:
   Navigate to `http://localhost:3000` to experience the website.
